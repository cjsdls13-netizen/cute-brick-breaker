# 🐱 말랑 벽돌깨기

귀여운 파스텔 벽돌깨기 게임이에요.

▶ **플레이:** https://cjsdls13-netizen.github.io/cute-brick-breaker/

## 조작법
- 마우스 / 손가락으로 패들 이동 (키보드 ← → 도 가능)
- 클릭 · 탭 · 스페이스로 공 발사
- P / Esc: 일시정지, M: 소리 켜기/끄기

## 아이템
| 아이템 | 효과 |
|---|---|
| 🍓 | 패들이 10초 동안 커짐 |
| ⭐ | 공이 3배로 늘어남 |
| 🍦 | 8초 동안 공이 느려짐 |
| 💖 | 생명 +1 |

테두리가 있는 벽돌은 두 번 맞춰야 깨져요.
